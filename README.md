# The Sneaky One

Juego de impostores para jugar en familia: la tele (o cualquier pantalla) muestra la partida y cada jugador usa su móvil.

- Abrir `tele.html` en la pantalla común.
- Abrir `movil.html` en cada móvil y escribir el código de sala.
- Sin servidor propio: la tele lleva la partida y los móviles se conectan a ella por WebRTC (PeerJS).
- Para pruebas en un solo navegador: añadir `?local=1` (y `&tab=1` en cada pestaña de móvil).
